SpudVault privacy policy

Published by SpudVault.

Effective October 28, 2026. Applies to the SpudVault Firefox extension and its local Windows companion app.

Information used

SpudVault handles usernames, passwords, and the website addresses associated with those logins. The browser extension checks supported login forms to offer saving a submitted login, and matches saved accounts to the current website for confirmed autofill. Browser features are disabled until the user agrees to local data handling.

Saving and filling

Choosing Yes in a save prompt sends the username, password, and website origin to the installed SpudVault app using Firefox Native Messaging on the same computer. Cancelling, declining, or allowing that prompt to expire does not save the proposed login. Account lookup sends the current website origin to that local app and returns matching addresses and usernames without passwords. Only Confirm & fill requests the selected password and fills the website. SpudVault does not automatically submit the form. Filled values are accessible to the selected website, including its scripts and behavior.

Storage and recipients

The desktop app stores an encrypted vault under the current user's LocalAppData folder, using Windows DPAPI for that Windows account. SpudVault does not operate a cloud vault or remote password service. It does not send passwords or website history to its developer, sell data, use advertising, or include telemetry. The extension temporarily handles proposed or approved credentials in memory but does not persist them in extension storage. It stores the local enable/disable choice in Firefox's local extension storage, not sync storage. Website information is stored only as part of saved login records; there is no general browsing-history log.

Control and deletion

Every save and fill requires separate user confirmation. Privacy choices in the extension settings allow users to disable further browser handling. This does not retract data already given to a website. Users can edit or delete saved accounts in the desktop app. Removing the extension or uninstalling the app keeps the encrypted local vault unless the user separately deletes it. A source import document, clipboard contents, Windows backups, and VM snapshots are outside the extension's storage and deletion controls. Copied desktop passwords are cleared after 20 seconds when the clipboard still contains the copied value.

Protection and limits

No SpudVault account or cloud login is required. Windows-account encryption is the current unlock boundary; there is no separate master password or portable recovery feature. Other software running as the same Windows user may be able to access that user's data. Browser memory cannot be reliably erased immediately. SpudVault currently fills only supported top-level login forms on HTTPS sites and explicitly supported localhost HTTP test pages.

This public policy website

This policy page is hosted on GitHub Pages using the calendar site's domain. Visiting it does not send your SpudVault vault, passwords, or saved logins to this site. GitHub logs visitors' IP addresses for hosting security, as described in GitHub's Pages documentation and privacy statement. This page includes no advertising, tracking scripts, password forms, or third-party analytics added by SpudVault.
